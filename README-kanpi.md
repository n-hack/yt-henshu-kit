# 完コピ練習（kanpi）の設計メモ

作業AI・2026-10-15。依頼主「記録するだけだと意味ないからね！GOALはプロの動画編集者だから！」

型（per_full の記録）は、書いただけでは腕にならない。
**型だけを見て元の場面を作り直し、元と並べてコマ単位で比べ、ずれが線の内側に入るまで直す。**
線に入った型だけを「使える型」として次の新しい動画づくりに使う。

## 置き場

| もの | 場所 |
|---|---|
| 比べる道具（いま動く） | `tools/yt-henshu/kanpi.py hikaku ...` |
| 測る部品（saboranai と共通） | `tools/yt-henshu/sokutei.py` |
| 手抜きの門 | `tools/yt-henshu/saboranai.py`（30分おき） |
| 練習の記録（作る） | `state/yt-anime-1014/kanpi/<id>/<場面番号>/`（作った mp4・比べた結果 json・直した回数） |

## 流れ（1場面ずつ）

1. **選ぶ**：saboranai に合格した per_full から場面を選ぶ。最初はチャンネルごとに役割（フック・証拠・CTA など）が違う場面を1つずつ。
2. **材料をそろえる**：元のナレーションの声だけ（demucs の vocals）をその場面の秒で切る。素材は sozai2 にあるもの（効果音・BGM・絵）だけを使う。元動画のコマは使わない。
3. **型だけで作る**：per_full のその場面の欄（telop の文字・区切り・大きさ・色・座布団、visual、anim、transition、sfx、bgm）と、そのチャンネルの rules だけを読んで、作業AIの描画（build/anim.py など）で作る。**元動画を見ながら合わせない**（見て合わせると型の穴が見えない）。
4. **比べる**：`kanpi.py hikaku <元> <元の開始秒> <作った> 0 <秒数> --voice <声.wav> --voice-t0 <元の開始秒>`
5. **直す**：不合格の項目ごとに、まず「型の記録が足りない／違う」のか「作業AIの作り方が違う」のかを分ける。
   - 型が足りない・違う → per_full のその場面を直す（作業者に返す／作業AIが元を見て書き足す）。直した型でもう一度 3 から。
   - 作り方が違う → 道具（anim.py など）を直す。
6. **合格するまで繰り返す**。回数・何を直したかを `kanpi/<id>/<場面>/log.jsonl` に1行ずつ。
7. **合格した型だけ**を `kata/kanpi-ok.json` に入れる（新しい動画を作るときはここから引く）。

チャンネルごとに 5場面続けて1回目で合格したら、そのチャンネルの型は「使える」とし、場面ではなく 1分の区間で同じことをする。最後は1本まるごと。

## 合格の線（kanpi.py の LINE と同じ）

測り方は saboranai と同じ `sokutei.py`（全コマの差 480x270 輝度・場面転換＝画面の30%以上が24より大きく変わる・6コマ以内は1回）。fps は元動画（多くは 29.97）。

| 項目 | 測り方 | 合格 |
|---|---|---|
| 場面転換 | 両方を全コマで差を取り、カットの時刻を ±2コマで1対1に対応づける | 元の 90% 以上を拾う・作ったものの余計な切り替え 15% 以下・ずれの中央値 1コマ以内 |
| 画面の変化の頻度 | 「目に見える差」（輝度差8超の画素が5以上）の立ち上がりの回数/分と間隔 | 回数/分が元の ±15%・間隔の中央値が元の ±10% |
| テロップの出入り | 2コマ/秒で 1920x1080 のコマを macOS Vision で読み、文字列ごとに出た秒・消えた秒。文字の重なり60%以上・3秒以内で対応 | 元のテロップの 85% 以上が出る・出のずれ 中央2コマ以内／90%点4コマ以内・消えのずれ 中央3コマ以内 |
| 効果音の位置 | 両方の音の立ち上がり（spectral flux）から、同じナレーション（声だけ）にある立ち上がりを外し、残りを ±2コマで対応 | 元の 85% 以上を拾う・作ったものの余計な音 20% 以下 |
| 色 | 毎秒のコマを 160x90 にして画素ごとの色差（CIE76 ΔE）の中央値 → その中央値 | 8 以内 |
| 構図 | 毎秒のコマの輪郭の強さ（約80x45）の相関 → 中央値 | 0.80 以上 |

注意（測れる細かさ）
- テロップの出入りは OCR を 2コマ/秒で回すので、細かさは約±7コマ。線を詰めるときは `--ocr-fps 10` などに上げる（遅くなる）。中央値・90%点が線に入っても、最後の詰めは場面転換と同じ全コマの差（テロップの範囲だけの差）で見る ── 次に足す。
- 効果音は「声だけ」を渡さないと声の立ち上がりで水増しされる。必ず `--voice` を付ける。
- 色と構図は毎秒なので、アニメーションの途中のコマ（ポップ・ズーム）は見ていない。アニメの出切るコマ数とイージングは per_full の anim を、場面転換と同じ全コマの差で後から足す。
